## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ConfigPanel → PATCH /projects/{id} | User-typed filename and selected format leave the browser; all validation/sanitization is enforced server-side (Plan 01) |
| Download `<a>` → GET /projects/{id}/download | Browser follows a server URL; Content-Type/Content-Disposition are set by the server, not the client |

| T-06-06 | Information Disclosure | download link | low | mitigate | The `<a>` targets only `/projects/{id}/download`; the served path is resolved server-side from the DB, never from any client string |
