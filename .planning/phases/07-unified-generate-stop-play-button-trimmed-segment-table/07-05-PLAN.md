<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Human-verify the unified buttons, joined-output Play, edit-reverts, trimmed table, and layout fix end-to-end</name>
  <action>Pause for human verification — do not auto-advance. Present the what-built summary and walk the developer through the how-to-verify steps below on the deploy target, then wait for the resume signal. The Pitfall 2 regenerate-with-existing-output check (step 7) is mandatory, not optional.</action>
  <what-built>The unified yellow/red/green Generate/Stop/Play button across all four sites (segment rows, ConfigPanel character rows, CharacterCard wizard rows, batch Generate All), the joined-output green Play, the removed Status column, and the CastWizard layout fix.</what-built>
  <how-to-verify>
    1. Open a project with segments. In the segment table, confirm each row shows ONE button: amber "Generate Preview" when no audio, and confirm there is NO separate "Status" column (TBL-05).
    2. Click "Generate Preview" on a segment — it turns red "Stop Generation" (with a spinner) while generating, then green "Play" when done. Click "Play" — the segment audio plays.
    3. Edit that segment's text — its button reverts to amber "Generate Preview" with no status badge anywhere (GEN-12).
    4. In the Config Panel character list, repeat 2-3 for a character preview row (green Play after generating, reverts to amber after editing the character's voice/name) (GEN-10, GEN-12).
    5. Open the Cast Review wizard. Confirm each CharacterCard preview control is the same amber/red/green button and now has a working Stop (click Generate then Stop mid-flight — it stops, no backend restart needed) (D-01). Confirm the character-card column sizes to its content and does NOT stretch to full window height (D-05). Confirm SegmentPreview on the right is still a plain text preview with no controls (D-03).
    6. Batch: click the "Generate All" button (amber). It turns red "Stop Generation" while running, and once the joined file is ready the SAME button becomes green "Play" and plays the joined output in-browser. The blue "Download" button is still a separate button (D-04) (GEN-11).
    7. CRITICAL (Pitfall 2): on a project that ALREADY has a completed joined output, click "Generate Preview" (Generate All) again. Confirm the button shows RED "Stop Generation" during the re-run — it must NOT show green "Play" while the batch is actively running (that would play the stale previous file).
  </how-to-verify>
  <resume-signal>Type "approved" if all 7 checks pass, or describe which check failed.</resume-signal>
