<objective>
Deliver the core editable segment table with per-row generation and a content-hash cache — the central vertical slice of Phase 3. After this plan a user can open a ready project, edit any cell, generate/hear a single row's audio, and have an edit-then-regenerate reuse cached audio for unchanged rows.

This plan also front-loads ALL Phase 3 schema additions (Segment generation fields + Project.created_at/output_path) so later plans never touch models.py.

Purpose: TBL-01/02/04 (editable table, per-row generate) and GEN-02/03 (content-hash cache, regenerate-only-changed-row).
Output: New Segment/Project columns, cache_key.py, WAL+migration in db.py, per-segment generate/patch/audio endpoints, and the SegmentTable + ProjectScreen frontend.
</objective>

## Phase Goal (MVP user story)

**As a** user converting a book to a multi-voice audiobook, **I want to** edit the full segment table and generate/regenerate per-row audio with caching, **so that** I can fine-tune each line and only re-synthesize what I actually changed.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | per-segment .wav filename / cache key | medium | mitigate | Filenames are server-generated uuid4().hex; cache_key is a hex sha256 digest — never derived from raw client text (mirrors _generate_preview line 343) |
| T-03-02 | Tampering (Input Validation) | PATCH /segments/{id} body | low | mitigate | SegmentPatch is a Pydantic model with typed optional fields; unknown fields are ignored, same discipline as CharacterPatch |
| T-03-03 | Denial of Service | rapid PATCH → many background synth tasks | low | accept | Single-user tailnet tool; last-request-wins version guard discards stale in-flight work. No rate limiting needed at this scale |
| T-03-SC | Tampering | package installs | low | accept | No new pip/npm packages this plan (RESEARCH Package Legitimacy Audit: not applicable — stdlib hashlib only). No install checkpoint required |
</threat_model>
