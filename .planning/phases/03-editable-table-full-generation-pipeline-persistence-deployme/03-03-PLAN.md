## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tailnet client → FastAPI | Batch generate + stream subscribe requests |
| backend → filesystem | Per-segment .wav files + joined output file written/read |
| backend → GPU TTS container | Batch synth calls over the internal pod network |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Tampering | joined output + per-segment .wav filenames | medium | mitigate | Server-generated uuid4().hex filenames; join reads only DB-stored audio_paths, never client strings |
| T-03-07 | Denial of Service | SQLite write contention under batch + per-row + SSE reads | medium | mitigate | WAL + busy_timeout from plan 03-01; every batch transaction is fetch→mutate→commit with no synth call held inside the session (Pitfall 5) |
| T-03-08 | Repudiation / data integrity | stale 'generating' row after crash silently skipped | high | mitigate | Reset stale 'generating' rows to 'pending' at the start of every batch invocation (Pitfall 1); persist status after every segment so resume is accurate |
| T-03-09 | Tampering | mid-batch per-row edit clobbered by stale batch write (or vice versa) | medium | mitigate | Last-request-wins generation_version guard on every write (Pitfall 2) — flagged in CONTEXT D-02 for real-hardware coverage |
| T-03-SC | Tampering | package installs | low | accept | No new pip/npm packages (stdlib asyncio/hashlib, existing fastapi SSE). No install checkpoint required |
</threat_model>
