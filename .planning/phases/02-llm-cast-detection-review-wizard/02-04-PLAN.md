## Phase Goal

**As a** reader, **I want to** correct the detected cast (rename/merge/edit) and assign each character a voice whose preview is ready to play instantly, **so that** I fine-tune the narration with minimal effort.

This slice adds the backend the review wizard needs: character mutation + merge, the preset voice list, and eager preview generation with instant playback. The React UI consuming these lands in Plan 05.

<objective>
Add the wizard's backend surface — character edit/merge (WIZ-02), voice assignment with a preset list (WIZ-03), and eager, race-safe voice-preview generation + serving (WIZ-04/WIZ-05, D-16) — reusing Phase 1's `tts_client.synthesize()`.

Purpose: All interactive cast-editing state round-trips to persistence (no client-only draft), and previews are pre-generated so playback is instant. The one real hazard is the eager-generation race (Pitfall 5), handled with a version stamp.
Output: `voices.py` (preset list), PATCH/merge/preview/voices endpoints, and an endpoints test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> PATCH/merge/preview endpoints | Untrusted character-edit payloads and id path params cross into the backend |
| backend -> tts_client (preview synth) | Reuses the Phase 1 GPU/CPU-isolated HTTP boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10 | Tampering | preview WAV path construction | medium | mitigate | Preview files written under PREVIEW_DIR with `uuid4().hex` names; no client string ever used to build the path. |
| T-02-11 | Tampering | stale preview from eager-gen race | medium | mitigate | Per-character `voice_version` stamp; `preview_audio_path` written only if the stamp is still current (last-request-wins, Pitfall 5). |
| T-02-12 | Input Validation | PATCH/merge request bodies | low | mitigate | Pydantic/FastAPI validates body shapes; merge 404s on missing/cross-project ids before any mutation. |
| T-02-13 | Denial of Service | unbounded eager preview tasks on rapid re-assign | low | accept | Single-user tool; per-character version stamp collapses redundant writes. Bounded by human click rate — no queue needed. |
</threat_model>
