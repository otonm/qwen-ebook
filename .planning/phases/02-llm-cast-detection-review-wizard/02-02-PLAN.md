## Phase Goal

**As a** reader who owns a long text, **I want to** upload it (now including .epub) and have the app auto-detect its cast and split it into voice-tagged segments, **so that** I get a multi-character narration set up with minimal manual editing.

This slice extends the working upload path (Plan 01) with a new input capability: after this plan, a user can upload an EPUB and it flows through the same analysis pipeline as a .txt.

<objective>
Add EPUB ingestion (ING-02): extract reading-order, footnote-stripped, non-narrative-filtered, chapter-preserving narrative text from an uploaded .epub and feed it into the Plan 01 analysis pipeline, with fail-fast rejection of unparseable chapters (D-09..D-13).

Purpose: The book's own structure (spine order, chapters) is what the LLM casting depends on; getting extraction right (not manifest order, no footnote noise, no cover/TOC boilerplate) directly determines cast-detection quality.
Output: `epub_parser.py`, a `.epub` test fixture, and a `/projects` upload branch that routes .epub through the parser.
</objective>

## Trust Boundaries

| browser -> POST /projects (.epub) | Untrusted EPUB (a ZIP container of XHTML) crosses into the backend and gets decompressed + XML-parsed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-04 | Denial of Service | EPUB decompression (zip-bomb) | high | mitigate | `_read_upload_bounded(file, MAX_UPLOAD_BYTES)` bounds the *compressed* upload before `epub.read_epub` ever decompresses it — ebooklib does not cap decompressed size. |
| T-02-05 | Information Disclosure | XHTML XML parse (XXE) | high | mitigate | Parse via BeautifulSoup+lxml default (`recover=True` behavior); never set `resolve_entities=True`/`no_network=False`. lxml disables entity/network resolution by default. |
| T-02-06 | Tampering | EPUB-internal item names/hrefs | medium | mitigate | No filesystem path is ever built from an EPUB-internal string; extraction is in-memory only, persisted under the server uuid Project id. |
| T-02-SC | Tampering | `uv add ebooklib beautifulsoup4 lxml` | high | mitigate | Task 1 blocking-human legitimacy checkpoint against pypi.org before install. |
</threat_model>
