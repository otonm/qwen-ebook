## Phase Goal

**As a** reader, **I want to** review the auto-detected cast on one screen, fix names/merges/descriptions, assign each character a voice, and hear an instant preview, **so that** I set up a multi-character narration with minimal manual editing.

This is the final slice: the React wizard that makes the whole phase visible and usable in the browser, consuming the endpoints from Plans 01 and 04.

<objective>
Build the single-page cast-review wizard UI (WIZ-01..05, D-14/D-15/D-16) on the existing Vite/React/shadcn scaffold: upload (.txt/.epub) → SSE-driven analyzing state → cast cards with inline edit/merge/voice-assign and instant native-audio preview → read-only segment preview, per the approved UI-SPEC.

Purpose: Delivers the differentiating casting experience end-to-end in the browser and resolves the UI-SPEC's single non-blocking FLAG (declare focal point + icon-button aria-label approach).
Output: `api/client.ts`, `useAnalysisStream.ts`, and the Upload/CastWizard/CharacterCard/SegmentPreview components wired to the backend.
</objective>
