Purpose: This is the engine half of the phase — the physical swap machinery the backend orchestration (Plan 02) and UI (Plan 03) drive. It also closes STATE.md's two open Phase 5 blockers (VRAM fragmentation baseline, speaker-list parity) with a real-hardware swap-cycle test.
Output: Swappable `ensure_loaded()`, the load route, and a passing real-hardware VRAM swap-cycle test.
</objective>

## Artifacts this phase produces (Plan 01)

- `MODEL_CHOICES: dict[str, str]` in `backend/tts_service/model.py` — the two hardcoded id→HF-repo mappings (`"1.7b"`, `"0.6b"`). No generic registry.
- `ensure_loaded(model_id: str) -> None` — no-op if already resident, else the 7-step swap (lock → del old → gc.collect → empty_cache → from_pretrained → re-apply patch → re-derive default speaker).
- `_loaded_model_id: str | None` — module global tracking the resident id.
- `_pick_default_speaker(supported: list[str]) -> str` — extracted narrator-preference logic, callable per swap.
- `_apply_stopping_criteria_patch(model_instance) -> None` — Phase 4's talker/speech-tokenizer monkeypatch, re-applied to each fresh instance.
- D-07 speaker fallback in the synth path: an unknown resolved speaker falls back to the resident model's `DEFAULT_SPEAKER`.
- `POST /model/{model_id}/load` route in `backend/tts_service/server.py`.
- `backend/tts_service/tests/test_model_swap_hardware.py` — GPU-gated swap-cycle VRAM/parity test.
