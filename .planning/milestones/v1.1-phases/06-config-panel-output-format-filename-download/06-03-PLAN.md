<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: Human-verify format selection, filename, and download end-to-end</name>
  <action>Pause for human verification — do not auto-advance. Present the what-built summary and walk the developer through the how-to-verify steps below on the deploy target, then wait for the resume signal.</action>
  <what-built>
    Server: per-project `output_format` (FLAC/MP3/Opus) and `output_filename` columns, a `PATCH /projects/{id}` config endpoint, a 3-way ffmpeg codec dispatch in the join step (with delete-old-output-first), and a `GET /projects/{id}/download` route serving the joined file with the correct Content-Type and filename.
    UI: the Config Panel's Output Format is now an editable dropdown, Output Filename is an editable input with a live `.ext` suffix, and a blue Download button appears once output exists.
  </what-built>
  <how-to-verify>
    Preconditions: backend + frontend running on the deploy target (rebuild the backend image via Podman/Quadlet if you changed backend code; the frontend build is served from the backend static dir). Open the app over Tailscale and load a project that already has generated segment audio (or generate a short one).
    1. In the Config Panel, open the Output Format dropdown — confirm it shows exactly FLAC, MP3, Opus (no WAV). Select MP3.
    2. In the Output Filename field, type a name containing an illegal char and an extension, e.g. `my/test:book.wav`, then click elsewhere (blur). Confirm the field re-displays a sanitized name (illegal chars gone, extension dropped — e.g. `mytestbook`) and the suffix beside it reads `.mp3`.
    3. Change the format dropdown to Opus — confirm the suffix beside the filename updates to `.opus`.
    4. Click Generate All and wait for it to finish. Confirm the blue Download button becomes enabled.
    5. Click Download. Confirm the browser saves a file named `mytestbook.opus`.
    6. Play the downloaded file (any player) — it should play as audio. Optionally run `ffprobe -v error -show_entries format=format_name -of default=nk=1:nw=1 <file>` and confirm it reports `ogg` for the .opus download.
    7. Repeat step 4-5 once with format = FLAC (filename can stay) — confirm the previous Opus output file on the server is gone (only the latest persists) and the new download is `mytestbook.flac` and plays.
  </how-to-verify>
  <resume-signal>Type "approved" if all steps pass, or describe which step failed and what you observed.</resume-signal>
